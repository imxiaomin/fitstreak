# Third-party visual assets

FitStreak includes a selected subset of [Workout Guide](https://github.com/bryllim/workout-guide), pinned to commit `aac599224bb9780305239607ef98540b7e0ce389`.

- Creator: [Bryl Lim](https://bryllim.com).
- Original pose artwork for some exercises: [Everkinetic](https://github.com/everkinetic/data).
- Visual asset license: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/), [legal code](https://creativecommons.org/licenses/by-sa/4.0/legalcode).
- Included visual files: `apps/web/src/static/exercises/**` (PNG) and `design/workout-guide/source/**` (SVG).
- Changes by FitStreak: no changes to image files; a curated selection and Chinese labels were added in separate application code.
- Individual creator, upstream source links and upstream adaptation records: [selected manifest](design/workout-guide/manifest.json).
- Original notices: [ATTRIBUTION](design/workout-guide/ATTRIBUTION.md), [LICENSE-ASSETS](design/workout-guide/LICENSE-ASSETS), [LICENSES](design/workout-guide/LICENSES.md).

These illustrations retain CC BY-SA 4.0, including its attribution and share-alike requirements for adaptations. The application's own code license does not replace the asset license. FitStreak's custom navigation/action icons in `design/icons` and `static/icons` are original project assets, not Workout Guide artwork.
