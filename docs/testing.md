## 覆盖范围

- 认证：无令牌返回401、演示开关、微信code2Session上游成功及失败的MSW模拟、重复微信身份返回同一用户、上游session_key不返回客户端。
- 计划：创建、修改、归档、名称空白、非法日期、分钟范围、训练日去重、用户ID注入、跨用户修改与打卡拒绝。
- 打卡及统计：当天记录、禁止客户端日期、重复409、同日多计划计两次但仅一个运动日、零填充、历史快照、归档后历史统计不变、时区午夜和闰日、连续打卡计算。
- 数据库：分钟CHECK约束和跨用户复合外键约束。本地测试使用PGlite执行SQL；CI通过TEST_DATABASE_URL将接口集成测试连接到真实PostgreSQL 17，两个适配器均已验证。
- 页面：375、768、1440像素宽度；中英首页及主要英文功能页无横向溢出；表单在视口内；创建、编辑、打卡、归档、统计、文章详情翻译、个人信息保存、空态、无效输入保留、500重试、401回到登录、访客知识浏览。
- 真实联调：浏览器创建“真实接口联调”计划，打卡37分钟，刷新后仍为已完成，统计与历史均显示37分钟。

测试源代码位于 `tests/`，浏览器机器可读结果为 `test-results-e2e.json` 与 `test-results-live.json`，界面证据位于 `screenshots/`。报告中的路径是仓库相对路径。

## 已修复问题

1. 小程序入口组件空脚本导致构建失败，改为明确组件导出。
2. PostgreSQL适配层泛型签名与pg返回类型不一致，统一数据库接口。
3. 历史查询日期投影与ORDER BY重名，显式使用表限定列。
4. uni-app H5按钮缺少语义，补充role、键盘操作及禁用状态；图标标记为装饰，避免按钮名称混入符号。
5. 每周目标圆环原为固定样式，改为按真实运动天数与目标计算进度。
6. 访客无法从界面进入公开知识页，修正渲染与公开请求流程。
7. PGlite文件数据库首次启动父目录不存在，增加自动创建父目录。
8. Word默认标题下划线和等宽表格影响阅读，移除标题边框并设置明确列宽；完成修订后逐页复查。

## 重现命令

```sh
npm ci
npm run build
npm test
npm run test:e2e
npm run test:live
npm run api:export
```

MSW为进程内模拟数据服务，重启会重置；真实联调使用 `.data/live-verification` 的隔离文件数据库，不连接生产用户数据。
