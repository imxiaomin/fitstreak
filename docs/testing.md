## 已修复问题

1. 小程序入口组件空脚本导致构建失败，改为明确组件导出。
2. PostgreSQL适配层泛型签名与pg返回类型不一致，统一数据库接口。
3. 历史查询日期投影与ORDER BY重名，显式使用表限定列。
4. uni-app H5按钮缺少语义，补充role、键盘操作及禁用状态；图标标记为装饰，避免按钮名称混入符号。
5. 每周目标圆环原为固定样式，改为按真实运动天数与目标计算进度。
6. 访客无法从界面进入公开知识页，修正渲染与公开请求流程。
7. PGlite文件数据库首次启动父目录不存在，增加自动创建父目录。
8. Word默认标题下划线和等宽表格影响阅读，移除标题边框并设置明确列宽；完成修订后逐页复查。

## 重现命令

```sh
npm ci
npm run build
npm test
npm run test:e2e
npm run test:live
npm run api:export
```

MSW为进程内模拟数据服务，重启会重置；真实联调使用 `.data/live-verification` 的隔离文件数据库，不连接生产用户数据。
